# resumo-lab3
Este repositório contém o resumo das lições aprendidas durante o desenvolvimento do lab na DIO.
Neste desafio do bootcamp Microsoft Azure Essentials, pude aprender um pouco mais sobre como funciona a criação e configuração de um banco de dados na nuvem usando o Microsoft Azure.

Banco de Dados na Nuvem
Um banco de dados é utilizado para armazenar, organizar e consultar informações. Quando utilizamos a nuvem, não precisamos manter toda a infraestrutura física por conta própria, pois os recursos são disponibilizados pelo provedor de nuvem.

No Azure existem diferentes serviços de banco de dados, cada um indicado para diferentes necessidades.

Azure SQL
O Azure SQL é um conjunto de serviços de banco de dados SQL oferecidos pela Microsoft na nuvem.
Uma das vantagens de utilizar um serviço gerenciado é não precisar cuidar diretamente de toda a infraestrutura, podendo focar mais no banco de dados e na aplicação.

Criando uma instância - 
Durante o laboratório, conheci algumas das principais etapas para configurar uma instância de banco de dados no Azure:
Criar ou selecionar um Resource Group;
Escolher a região onde o recurso será criado;
Definir as configurações da instância;
Configurar opções de computação e armazenamento;
Definir o acesso e as configurações de segurança;
Revisar as configurações antes da criação;
Criar e acompanhar a implantação do recurso.

O Resource Group ajuda a organizar os recursos que fazem parte de um mesmo projeto, facilitando também o gerenciamento e o controle dos recursos.

Segurança
Assim como nos outros serviços da nuvem, a segurança precisa ser considerada desde a configuração do recurso.

Alguns cuidados importantes são:
Utilizar senhas seguras;
Controlar quem pode acessar o banco;
Configurar corretamente as regras de rede;
Não compartilhar informações de acesso;
Não deixar recursos desnecessários ativos.

Custos
Outro ponto importante que aprendi é que precisamos acompanhar os custos dos recursos utilizados na nuvem.
O Azure possui ferramentas para acompanhar os gastos e configurar alertas de orçamento. Também é importante excluir recursos que não estão mais sendo utilizados, principalmente em ambientes de estudo.
